# Vennix — Premium Digital Marketing Agency

A production-ready, single-page agency website built with **Next.js 14 (App Router)**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## ✨ Features

- Premium dark mode (`#0a0a0f`) with glassmorphism UI
- Purple → Cyan gradient accent system (`#8b5cf6` → `#06b6d4`)
- Smooth fade-up scroll animations via Framer Motion
- Sticky glass navbar with mobile hamburger menu
- Filterable portfolio (All / SEO / Paid / Content / Social)
- Working contact form via **Web3Forms** (access key pre-configured)
- Honeypot spam protection
- Fully responsive, SEO metadata included

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## 🏗️ Production Build

```bash
npm run build
npm start
```

## ☁️ Deploy to Vercel

```bash
npm i -g vercel
vercel
```

Or connect the GitHub repo at [vercel.com/new](https://vercel.com/new) — zero config required.
